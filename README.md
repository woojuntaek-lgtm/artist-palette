# 나만의 색 팔레트

오늘의 감정을 고치지 말고, 색으로 남겨 보세요. 에니어그램 4번(예술가) 이야기를 바탕으로, 감정을 색으로 섞어 기록하는 **감정 색 일기**, 부러움을 이미 가진 것으로 바꾸는 **가시를 꽃으로**, 1분 **감성 날씨** 점검을 담은 앱입니다. 「에니어그램 4번 예술가」 강의 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/artist-palette/**

## 특징
- 🎨 오늘의 내 색: 12가지 감정 중 최대 3개 + 세기 → 섞인 색과 시적인 색 이름(예: "늦가을 저녁의 보랏빛 그리움"), 한 줄 메모, 나의 감정 팔레트(기기 저장, 최근 60개)
- 🌵 가시를 꽃으로: 부러운 것 → "정말 원하는 것인가, 없다고 느끼는 마음인가" → 이미 가진 것 세 가지가 꽃으로 피어나는 카드
- 🌦️ 감성 날씨: 12문장 1~5점 → 깊이·가시·균형과 상태(균형 잡힌 예술가 / 가시 주의보 / 홀로 깊어지는 가을 / 담백한 하루 / 잠시 흐린 날), 맞춤 처방
- 🎨 4번 한눈에: 한 줄 정의, 동양 수리(金·辛·서·흰색, 가을), 안테나와 상처, 날개, 스트레스·성장 방향, 아웃사이더 4번에게

성찰을 돕는 참고용이며 심리검사나 전문 상담을 대신하지 않습니다. 입력 내용은 기기 밖으로 나가지 않습니다.
